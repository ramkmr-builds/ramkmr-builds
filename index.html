IoT-Based Ganga Pollution Detection, Source Identification and Alert System

Detect pollution, map affected areas, find possible sources and alert the authorities.

How it works

  1. Water sensors measure pH, turbidity, temperature, conductivity and dissolved oxygen.
  2. An ESP32 or Arduino checks the readings and sends them online.
  3. The database stores readings, locations and alerts.
  4. The dashboard compares upstream and downstream points and ranks hotspots.
  5. Alerts go to the monitoring team, who inspect, sample and record action.

Project status

Design phase. First prototype: two monitoring points, one before and one after a suspected outlet, with an alert when the difference crosses a threshold. This website uses demo data until sensors or a real data source are connected.

Limitations

  • Sensors need cleaning and calibration.
  • Basic sensors cannot detect every chemical.
  • Readings alone cannot prove which factory is responsible.
  • Poor network, floods and weather can affect data.
  • False alerts are possible, so lab verification is needed.
